Resilience Copilot is a safety-bounded workflow agent for disaster triage: it turns messy crisis notes into a sixteen-section, responder-reviewed workflow with Transfer Brief, Audit Trace, and structured JSON export.

Gemma 4 composes responder-facing language under deterministic sidecar constraints; the sidecar checks official-resource routing, blocks unsupported claims, and keeps final decisions with human responders.

An offline learning sidecar records local validation feedback into an experience ledger, validation feedback memory, Memory Write Gate, long-term memory system, LangGraph-compatible graph orchestration, strategy reflection, skill library, and no-network tool sandbox. Raw runtime input is quarantined; only validated, human-reviewed feedback can be promoted, and protected safety invariants cannot be rewritten by memory.

It is not a fully autonomous responder and does not replace emergency services. It does not diagnose, invent shelter capacity, invent transport availability, or present unverified rumors as fact.
